# 提交说明 · 电影评分预测

## 一、提交文件

`test_pairs_pred.csv`　共 **100,000 行**（不含表头），UTF-8 编码，逗号分隔。

| 列序 | 列名 | 说明 |
|---|---|---|
| 1 | `userId` | 用户 ID，与 `test_pairs.csv` 逐行一致 |
| 2 | `movieId` | 电影 ID，与 `test_pairs.csv` 逐行一致 |
| 3 | `timestamp` | 时间戳，与 `test_pairs.csv` 逐行一致 |
| 4 | `rating` | **预测评分**，取值 0.5 ~ 5.0，保留 4 位小数 |

**前三列未做任何改动**，直接沿用原表，可逐行对齐核验。第 4 列 `rating` 为模型输出的预测评分，
列名与原始 `ratings.csv` 的评分列一致。

预测值分布：均值 **3.5767**、标准差 **0.5706**、最小值 0.5000、最大值 5.0000，无缺失值。

## 二、方法概要

**Bias-MF（偏置 + 矩阵分解）**

```
r̂ = μ + b_u + b_i + p_u · q_i
```

- `μ`：全局均值 3.5767（3,190 万条评分直接求平均）
- `b_u`、`b_i`：用户 / 电影偏置，用交替最小二乘闭式解出，用户侧强收缩（λ_u=50）、电影侧弱收缩（λ_i=2）
- `p_u · q_i`：64 维隐向量内积，SparseAdam 迭代 6 轮

**训练配置**：学习率 1e-3、因子 L2 系数 3e-2、批大小 8192、全量 31,900,204 行训练。
三个随机种子（1/2/3）各训一遍，预测结果等权平均。

## 三、精度

| 口径 | RMSE |
|---|---|
| 验证集（时间尾部截断，61,574 行） | **0.8386** |
| 　· 真实数据半区 | 0.8073 |
| 　· 合成数据半区 | 0.8687 |
| 稀疏历史用户模拟（1,043 人，64,666 行） | 0.9243 |
| **按测试集真实构成加权的预期值** | **0.8954** |

测试集有 65,168 行（65.2%）来自仅 1,043 位「训练表中只有 5 条评分」的用户，这些用户人均需预测 62 条。
上表最后一行是按 0.652 × 0.9243² + 0.348 × 0.8386² 加权得到的预期测试集 RMSE。

## 四、复现

数据放到 `rating_prediction/data/`（`ratings.csv` 与 `test_pairs.csv`），然后：

```bash
python scripts/audit.py                    # 数据审计
python scripts/eval_bias.py                # 偏置预拟合
python scripts/train_mf.py --final --dim 64 --l2 3e-2 --kappa 0 --lr 1e-3 --epochs 6 --seed 1 --tag G1
python scripts/train_mf.py --final --dim 64 --l2 3e-2 --kappa 0 --lr 1e-3 --epochs 6 --seed 2 --tag G2
python scripts/train_mf.py --final --dim 64 --l2 3e-2 --kappa 0 --lr 1e-3 --epochs 6 --seed 3 --tag G3
python scripts/make_submission.py --preds G1 G2 G3 --no-valid
```

单卡（RTX 3050 Laptop，4 GB）上单轮约 33 秒，三个种子全量重训约 10 分钟。
