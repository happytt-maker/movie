### P4 关键发现：三分之二的测试行只有 5 条历史
- type: content / role: hero / rhythm: peak / visual_role: anchor
- layout: 左 4:右 6（左三条发现列点，右 fig06 占 55%）
- description: 图 fig06 显示 65.2% 的测试行（65,168 条）来自 1,043 位「训练表里恰好 5 条」的用户，人均 62 条。左侧两条配套发现——① 测试行相对用户最后一条评分的间隔中位仅 0.1 天（我最初自建的验证集是 120 天） ② 两个半区统计几乎一致但 RMSE 差 0.06（真实 0.807 / 合成 0.869）。结论条：这条结构决定了后面所有设计——模型重心必须压在电影侧参数上，验证集必须专门模拟这批用户。
- density: 字数约 210 / 图片 1 / 留白约 22%
- anti_pattern: 禁止把 65.2% 做成巨型数字与图重复；禁止只说「数据稀疏」而不给具体人数

### P5 验证集：没有任何单一划分能同时复现测试集
- type: content / role: supporting / rhythm: valley / visual_role: none
- layout: 三行口径表（口径 / 行数 / 用户 / RMSE / 回答什么）+ 底部混合公式条
- description: 表三行——A 固定截断 2023-05-01（106,933 行 / 7,198 人 / 0.8539 / 选超参）、B 时间尾部 2023-07-01（61,574 / 5,480 / 0.8386 / 报告主指标）、C 稀疏历史模拟（64,666 / 1,043 / 0.9243 / 那 65% 的行有多难）。公式：0.652×0.9243² + 0.348×0.8386² → 预期 0.8954。结论条：口径错了，调出来的校正也是错的——口径 A 上「全局偏移 −0.06」的收益，到口径 B 上只剩下 0.0006。
- density: 字数约 300 / 图片 0 / 留白约 15%
- anti_pattern: 禁止把三个口径说成「三个模型」；禁止只报 0.8386 不提 0.8954

### P6 模型：四项相加，偏置先解、因子后学
- type: content / role: hero / rhythm: peak / visual_role: anchor
- layout: 公式条（满宽）→ 四项横排 → 训练四步流程条（均为原生 DSL，不用位图）
- description: 公式 r̂ = μ + b_u + b_i + p_u·q_i，四项含义逐条注释；下方 fig08 左半是预测结构、右半是训练四步（ALS 预拟合 → 作初值 → SparseAdam 只更新批内 → 6 轮输出）。结论条：选它的理由是数据形态——65% 的行只有 5 条历史，只有电影侧参数（b_i、q_i）能用 3,190 万条评分估稳。
- density: 字数约 180 / 图片 1 / 留白约 18%
- anti_pattern: 禁止把公式和结构图重复讲两遍；禁止贴代码

### P7 训练实现：一个让四组实验结果完全相同的初始化
- type: content / role: hero / rhythm: peak / visual_role: evidence
- layout: 左 6:右 4（左：坑一的对照表 + 说明；右 fig05 训练曲线）
- description: 坑一——零初始化：dim 16/32 × κ 0/10 四组实验 RMSE 完全相同（0.9256974204823673，18 位原样打四遍），因为 p=q=0 时 p·q=0 且梯度恒为 0，因子永远不更新；改 `normal_(std=0.01)` 后 0.9257 → 0.8603。坑二——立刻过拟合：lr 5e-3 + L2 1e-4 时训练 MSE 掉到 0.456、验证升到 0.876；改 L2 3e-2 + lr 1e-3 后曲线正常，第 8 轮触底后回升，故固定 6 轮。结论条：这两个坑贡献了本项目最大的两次单点收益，也都是「不看曲线看不出来」的问题。
- density: 字数约 280 / 图片 1 / 留白约 15%
- anti_pattern: 禁止把表格写成六行流水账（用 2×3 紧凑表）；禁止在结论条里重复表格数字

### P8 证伪：为短历史用户设计的门控，方向反了
- type: content / role: supporting / rhythm: valley / visual_role: evidence
- layout: 左 5:右 5（左：假设 + 公式 + fig03；右：三档结果的解释 + 为什么）
- description: 假设 g_u = n_u/(n_u+κ)，κ=10 时 5 条历史的用户因子只保留 1/3。实测稀疏群 RMSE：κ=0 为 0.92358、κ=10 为 0.92801、κ=100 为 0.93949——压得越狠越差。解释：q_i 由 3,190 万条评分训练，非常可靠；p_u·q_i 相当于拿用户看过的 5 部片做相似度检索，仍有信号，压小等于主动扔掉。结论条：动机合理的正则项也要在数据上验一遍，我最初的直觉在这里是错的。
- density: 字数约 260 / 图片 1 / 留白约 18%
- anti_pattern: 禁止把「失败」写成「探索过程中的有益尝试」这类空话；禁止隐藏 κ=0 才是最终选择

### P9 结果：从 1.0304 到 0.8386
- type: content / role: hero / rhythm: peak / visual_role: anchor
- layout: 左 6:右 4（左 fig01 阶梯图；右三 seed 表 + 分半区）
- description: 左图六档阶梯（全局均值 1.0304 / 用户均值 1.0012 / 电影均值 0.9577 / 偏置 ALS 0.9129 / Bias-MF 0.8396 / 三 seed 0.8386）。右侧三行表：三个 seed 分别 0.84013 / 0.83957 / 0.84008，等权平均 0.83858；分半区真实 0.8073、合成 0.8687。结论条：偏置项贡献了 0.118 的降幅、因子只再降 0.073——大部分增益来自「电影有多好」，不是「这个人多独特」。
- density: 字数约 200 / 图片 1 / 留白约 20%
- anti_pattern: 禁止把 0.8386 说成「测试集 RMSE」；禁止不给分半区数字

### P10 误差分析：损失不在长尾，在主流片
- type: content / role: supporting / rhythm: valley / visual_role: evidence
- layout: 左 6:右 4（左 fig02；右五行残差统计数字表 + 读法）
- description: 左图——≥1000 条评分的电影占 52.8% 的样本、47.8% 的平方误差；1–9 条的长尾只占 5.8% 样本、8.4% 误差，但它的 RMSE 最高（1.008）。右图残差：均值 −0.031、标准差 0.838、偏度 −0.59、落在 0.5/5.0 边界的仅 142 行。结论条：继续优化长尾没有意义；主流片上的残差已接近噪声，瓶颈是信息量而不是模型容量。
- density: 字数约 190 / 图片 2 / 留白约 18%
- anti_pattern: 禁止把两张图画成同一尺寸抢主次；禁止用「效果良好」这类无信息结论
