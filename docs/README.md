# 文档目录

存放课程项目的非代码交付物：

| 文件 | 内容 |
|---|---|
| `项目报告.md` / `项目报告.docx` | 问题定义、数据分析、系统架构、算法设计、实验设置、结果与消融、局限与改进 |
| `演示材料.pptx` | 答辩用幻灯片（8 页：结论、数据协议、架构、六任务、结果、消融、局限） |
| `个人贡献说明.md` | 承担工作、关键决策、时间投入、可复现自检 |
| `答辩记录.md` | 预设答辩问题与回答要点 |

> 任务书「八 提交成果」要求这些材料与代码一并提交。
> 报告与幻灯片可用脚本重新生成：
> `python scripts/build_report_docx.py`、`python scripts/build_slides.py`。
