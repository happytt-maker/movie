1. **最终 NDCG@10 从 0.8894 修正为 0.8604**（相对热门 +16.8%）。

## 4. 怎么复现 0.8604

```bash
# 前置：data/ml-32m 就位（约 911 MB，MD5 与官方 checksums.txt 一致）

# 1) 应用第 3 节的 4 个文件
# 2) 重训最终模型（约 75 秒）
python scripts/train_ranker.py --name ranker_full
# 3) 评测
python scripts/evaluate.py --pred results/top10_ranker_full.csv --name ranker_full
# 4) 审计
python scripts/audit_leakage.py
```

期望结果：`NDCG@10 = 0.86037`、`Recall@10 = 0.82374`，审计 6 项 PASS。
